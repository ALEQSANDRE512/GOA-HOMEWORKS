GOA

GOAL-ORIENTAL ACADEMY

GOA-ს აკადემია არის სივრცე, სადაც სტუდენტები ისწავლიან ვებ-განვითარების მუშაობას. GOA ასწავლის მოსწავლეებს და ამვდროულად ის უზრუნველყოფს მათ სოციალურ განვითარებას. ხოლო GOA-ს ძლიარი მხარე მისი ინდივიდუალური მიდგომაა ბავშვების მიმαრთ. GOA-ს აკადემია არის სივრცე, სადაც სტუდენტები ისწავლიᴀნ ვებ-დეველოპმენტს და ექნებათ შესაძლებლობა თვითონ გახდნენ რაზმის ლიდერი ან მენტორი და სხვა.

GOA-ს აკადემიის მიზნები

სტუდენტების ვებ-დეველოპმენტის უნარების განვითარება სტუდენტების სოციალური განვითარება სტუდენტების ინდივიდუალური მიდგომის უზრუნველყოფა სტუდენტების ლიდერობის უნარების განვითარება სტუდენტების მენტორობის უნარების განვითარება

რას ვისწავლით GOA-ში

GOA-ში ვისწავლით ვებ-დეველოპმენტის ძირითად ტექნოლოგიებს, რომლებიც გამოიყენება ვებ-გვერდების შექმნაში. ჩვენ ვისწავლით HTML, CSS და JavaScript ტექნოლოგიებს, რომლებიც უზრუნველყოფს ვებ-გვერდების სტრუქტურის და დიზაინის შექმნას. ასვე ვისწავლით back-end development-ს. მოკლედ რომ ვთქვათ ვისწავლით სრულად web development-ს ანუ გავხდებით full stack development-ები.

ჩემი საყვარელი წიგნი

ჩემი საყვერელი წიგინია "საიდუმლო კუნძული"

ის დაწერილი ჟიულ ვერნის მიერ

ჟიულ ვერნის „საიდუმლო კუნძული“ სათავგადასავლო რომანია. წიგნში მოთხრობილია ხუთი ადამიანის თავგადასავალი, რომლებიც საჰაერო ბურთით გაქცევის შემდეგ უკაცრიელ კუნძულზე აღმოჩნდებიან. მათ უწევთ ბუნებასთან ბრძოლა, საკვების მოძიება და თავშესაფრის აშენება. კუნძულზე ისინი ბევრ საიდუმლოსა და მოულოდნელ მოვლენას აღმოაჩენენ. ეს წიგნი გვასწავლის მეგობრობის, ერთიანობის, ცოდნისა და გამბედაობის მნიშვნელობას.

კოსმოსი

უზარმაზარი სივრცეა, რომელშიც განლაგებულია ყველა გალაქტიკა, ვარსკვლავი და პლანეტა. ეს ადგილია სადაც ადამიანი მარტო არაა

გალაქტიკა

ვარსკვლავების, პლანეტებისა და კოსმოსური მტვრის უზარმაზარი ერთობლიობაა. ჩვენი გალაქტიკაა ირმის ნახტომი.

შავი ხვრელი

კოსმოსური ობიექტია, რომელსაც ძალიან ძლიერი გრავიტაცია აქვს და მისგან სინათლეც კი ვერ აღწევს თავს.

მზის სისტემა

შედგება მზისგან და მის გარშემო მოძრავი რვა პლანეტისგან. მერკური, ვენერა, დედამიწა, მარსი, სატურნი, იუპიტრი, ურანი, ნეპტუნი.

ვარსკვლავები

ცხელი აირებისგან შემდგარი ციური სხეულებია, რომლებიც საკუთარ სინათლეს გამოსცემენ. მზეც ვარსკვლავია.

დედამიწა

დედამიწა პლანეტაა, რომელიც მზის გარშემო მოძრავს. იგი სულური პლანეტაა და შეიცავს ყველგზე ცხოვრებულ სივრცეს. ჩვენი სახლი.
